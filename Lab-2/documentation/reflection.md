# Reflection

## 1. Why are user stories preferred over directly assigning tasks?
User stories express functionality from the user's perspective and explain the value of the work. Acceptance criteria provide a basis for deciding whether the requirement has been satisfied.

## 2. How do story points help in sprint planning?
Story points provide a relative estimate of effort and complexity. Fibonacci values make increasing uncertainty visible as work becomes larger or more complex.

## 3. What happens if a story is too large for one sprint?
The story should be refined and, where appropriate, split into smaller independently valuable stories so that the work can be completed and tracked within a sprint.

## 4. What is the advantage of visualizing work on a Kanban/Scrum board?
A board makes status visible, helps identify pending or blocked work, and provides a shared view of progress.

## 5. How does the backlog support Agile planning?
The backlog keeps requirements organized, prioritized and traceable. The team can select suitable items for a sprint while retaining future work for later prioritization.
